Sicherheitsupdate: WIN Infinite Desktop wird jetzt mit Qt 6.11.3 statt Qt 6.8.3 ausgeliefert.

## Behoben

- **Qt-Sicherheitslücken** (CERT-Bund WID-SEC-2026-4373): Qt 6.8.3 enthält mehrere bekannte Schwachstellen, unter anderem in QtNetwork (HTTP/2, Cache-Control-Kopfzeilen, NTLM), im XML-Parser und in Qt Quick. Das Paket bringt jetzt Qt 6.11.3 mit, das diese Fehler behebt. Der Update-Check der Einstellungs-App lädt über QtNetwork von GitHub; auch dieser Weg nutzt jetzt die korrigierte Version.

## Installation

Direkt aus der Einstellungs-App aktualisieren oder in PowerShell:

```powershell
irm https://raw.githubusercontent.com/RandomNam3/win-infinite-desktop/main/install.ps1 | iex
```

Voraussetzungen: Windows 11 24H2 oder neuer, x64 (Windows on ARM führt das x64-Paket aus).
